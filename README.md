# 亚马逊FBM库存盘点 Skill

> 自动盘点亚马逊FBM库存，覆盖在库/待上架/在途/待发全链路，写入飞书预测表格并生成报告。

## 概述

这是一个面向 **Coze Agent** 的 Skill，用于每周自动执行亚马逊 FBM 库存盘点。通过处理 3 个 ERP 导出的 Excel 文件，自动计算在库、待上架、在途和待发库存，按发货计划单号去重后，将数据写入飞书销量预估表，并生成盘点报告。

**目标产品：** UKEEP\*调节哑铃25lb对装（实标） — SKU: CP.13300EQ01US

## 核心能力

| 能力 | 说明 |
|------|------|
| 📦 **在库统计** | 从库存监控看板筛选良品+海外仓+美亚，汇总总量和分仓 |
| 🚚 **在途跟踪** | 从物流在途表筛选未送仓货物，按 ATA/ETA+7天预估上架 |
| 📋 **待发整理** | 从发货计划表筛选待发批次，使用计划到货时间 |
| 🔗 **自动去重** | 按发货计划单号去重，避免在途和待发重复统计 |
| 📊 **飞书写入** | 写入基准日库存 + 各批到货信息到飞书销量预估表 |
| ✅ **数据校验** | 分仓合计、到货总量、销量合理性等自动校验 |
| 📝 **报告生成** | 输出完整的盘点报告，含库存总览和补货建议 |

## 安装方式

### 方式一：通过 Coze 商店安装
1. 在 Coze 中打开「技能商店」
2. 搜索「亚马逊FBM库存盘点」
3. 点击安装即可使用

### 方式二：手动导入
1. 将本仓库文件复制到你的 Coze Agent 工作区
2. 在 Coze 中加载该 Skill
3. 按流程上传 3 个 Excel 文件即可开始盘点

## 使用流程

```
用户上传3个文件 → Agent加载Skill → 自动执行盘点 → 飞书写入 → 输出报告
```

**需要你准备的 3 个文件：**

| 文件 | 来源 | 用途 |
|------|------|------|
| 库存监控看板 | ERP 系统导出 | 在库库存、待上架、分仓明细 |
| 物流在途导出 | ERP 系统导出 | 在途货物跟踪、送仓状态 |
| 发货计划 | ERP 系统导出 | 待发货物、计划到货时间 |

## 自定义配置

如需适配其他 SKU 或调整流程参数，修改 `SKILL.md` 中的**关键参数**部分：

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 目标SKU | 盘点产品 | CP.13300EQ01US |
| 盘点频率 | 执行周期 | 每周一次 |
| 预测周期 | 预测天数 | 60天 |
| 销量基准 | 日均销量计算方式 | 30天日均 |
| 在途上架预估 | 到港→上架天数 | ATA/ETA + 7天 |
